# CodeStash ⚡

CodeStash adalah aplikasi manajemen cuplikan kode (*code snippet manager*) berbasis web dengan estetika desain **Neubrutalism**.

## ✨ Fitur Utama
- **Estetika Neubrutalism:** Desain berani dengan batas tegas, bayangan tajam (*hard shadows*), dan palet warna kontras tinggi.
- **Syntax Highlighting:** Didukung oleh Prism.js untuk berbagai bahasa pemrograman (JavaScript, HTML, CSS, Dart, PHP, Python, SQL).
- **Manajemen Privasi:** Dukungan cuplikan publik & privat.
- **Pencarian & Filter Cepat:** Cari kode berdasarkan judul, tag, atau kategori bahasa.
- **Salin Kode Sekali Klik:** Fitur *copy-to-clipboard* instan dengan indikator status visual.
- **Otentikasi & Database Realtime:** Didukung oleh Supabase.

## 🚀 Menjalankan Proyek
Buka file `index.html` langsung di browser atau gunakan server lokal seperti Live Server / Python:
```bash
python3 -m http.server 8000
```
Lalu buka `http://localhost:8000` pada browser.
